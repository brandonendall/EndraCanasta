# Endra Canasta

**Created by Kathryn — an original Endra project.**

**Working title — Prototype 0.1**

Endra Canasta is a modern, social, highly customizable Canasta experience designed for Android and iOS.

## Core experience

- Learn & Practice
- Solo Play
- Casual Play
- Competitive Play
- Friends & Private Tables
- Rich profiles, friends, favorite partners, statistics and match history
- Player-controlled table, card, profile and interface customization
- Chat, localized Quick Chat and translation
- Fair-play-first server-authoritative multiplayer architecture

## Prototype 0.1

The first milestone is an interactive cross-platform product prototype. It will validate navigation, customization, social flows, competitive presentation and the four-player Canasta table before production multiplayer services are built.

Online players and match data may be simulated in this phase, but visible controls should respond so the prototype can be evaluated on a real Android device.

## Technology direction

Prototype 0.1 is planned around Flutter so Android and iOS can share the application UI and logic. Production online play will use a server-authoritative backend: clients will receive only information legally visible to their own seat.
